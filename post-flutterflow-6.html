Flutterflow 6.0

W. Glasbergen · 30 mei 2025 · 3 minuten om te lezen

Vier jaar geleden werd Flutterflow gelanceerd tijdens Google I/O, met als doel app-ontwikkeling radicaal te veranderen. Afgelopen woensdag werd het vierjarig bestaan gevierd en werd versie 6.0 gepresenteerd: een nóg krachtigere en slimmere tool. In deze blog een samenvatting van alle nieuwe features.

Custom code en classes

Classes zijn een belangrijk concept binnen object oriented programmeren (OOP). Een class is een soort template en beschrijft wat een object is en wat het kan doen. Zo kun je een class 'auto' hebben, met een kleur en merk, die kan starten, versnellen en remmen. Tot nu toe kon je in Flutterflow geen classes gebruiken en had je workarounds nodig. Met versie 6.0 importeer je eigen Dart-bestanden en gebruik je zelfgemaakte classes zoals Cart, CartItem of Product direct in Flutterflow. Voordelen van classes:

  • Objecten aanmaken en doorgeven tussen pagina's
  • Eigenschappen direct aan de UI koppelen
  • Complexe OOP-technieken gebruiken, zoals overerving, mixins en abstract classes
  • Nog in ontwikkeling: automatische synchronisatie van Dart-bestanden via de VS Code-extensie

Custom code expressions

Tot nu toe kon je kleine stukjes custom code schrijven binnen je action flows, handig voor een korte berekening of conversie. Met versie 6.0 schrijf je grotere multi-line Dart-code direct in eigenschap-velden. Perfect voor het formatteren van tekst, logica of complexe berekeningen. Verder:

  • De actie Execute Code voert code direct uit binnen je flow
  • De nieuwe inline editor biedt automatische suggesties en directe foutcontrole
  • Binnenkort: AI-aanvulling met begrip van projectvariabelen, zoals App State of gebruikersgegevens

Pagina's in bibliotheken

Bouw pagina's één keer en hergebruik ze overal: perfect voor loginflows, onboarding of formulierverwerking. Gebruik ze in navigatie-acties en geef variabelen door tussen pagina's. Binnenkort kun je pagina's ook inzetten voor navigatiebalken of als startpagina.

Figma-frames importeren

Tot nu toe kon je alleen brandkleuren en typografie uit Figma importeren; de rest van je ontwerp moest je nabouwen in Flutterflow. Met versie 6.0 importeer je complete frames als componenten. Dat maakt het veel sneller om een ontwerp over te zetten, en er wordt meteen een koppeling gemaakt met het Flutterflow-thema.

Teams en samenwerking

Vanaf juli kun je tegelijk lid zijn van meerdere Flutterflow-teams. Wisselen tussen werkruimtes zonder uitloggen wordt dan verleden tijd.

Integratie en automatisering

YAML-bewerkingen

Voer grootschalige aanpassingen uit door het YAML-bestand van je project direct te bewerken, met versiebeheer zoals bij Git. Pas bijvoorbeeld snel een themakleur aan op alle plekken in je applicatie. Je vindt dit onder 'Refactor Project' in het ontwikkelmenu.

Project API

Voor het eerst is er een REST API om projectdata te lezen en te bewerken. Dit opent de deur voor geautomatiseerde workflows en CI/CD-integraties.

MCP Server (experimenteel)

Er wordt gewerkt aan een officiële MCP Server waarmee je projecten aanpast, pagina's aanmaakt en refactors uitvoert, direct vanuit AI-tools zoals Claude.

Overige verbeteringen

  • Desktop-apps gebruiken nu de Monaco-code editor met realtime foutcontrole en slimme suggesties
  • Dart-bestanden importeren in elke pagina of component
  • Meer dan 200 nieuwe foutmeldingen voor sneller debuggen van variabele-bindingen
  • Meer dan 50 bugs opgelost tijdens de recente Bug Bash
  • Ondersteuning voor aangepaste typografie naast aangepaste kleuren
  • Een compactere en efficiëntere Firestore UX voor veldinstellingen
  • Verbeterde zoekfunctie, met een nieuw commando-menu en navigatie met het toetsenbord
